Dashboard analitik Human Resources yang dibuat dengan Tableau untuk memantau komposisi karyawan, tren karyawan, dan indikator SDM lainnya.

## 📸 Preview

![HR Summary](HR%20Summary.png)

## 📌 Ringkasan Proyek

Proyek ini mencakup alur kerja dashboard dari awal: perancangan mockup, penyiapan data, pembuatan visual, hingga ringkasan hasil analisis. Dashboard dirancang agar tim HR dapat memahami kondisi tenaga kerja dengan cepat.

## 🎯 Tujuan

- Menyajikan ringkasan kondisi karyawan dalam satu tampilan.
- Membantu tim HR mengambil keputusan berbasis data.
- Mendokumentasikan proses desain dashboard dari mockup hingga hasil akhir.

## 🛠️ Tools

- **Tableau** untuk visualisasi dashboard
- **draw.io** untuk mockup/wireframe
- **Photoshop** untuk ikon proyek
- **CSV** sebagai sumber data

## 📁 Struktur Repository

```
Tableau-HR-dashboard/
├── HumanResources.csv      # Dataset HR
├── HR Summary.png          # Tampilan dashboard
├── mockups.drawio          # Mockup/wireframe dashboard
├── Summary OverView.docx   # Ringkasan dan insight proyek
├── 00 Project Icons.psd    # Ikon yang dipakai pada dashboard
└── README.md
```

## 🚀 Cara Menggunakan

1. Clone atau download repository ini.
2. Buka Tableau, lalu hubungkan ke `HumanResources.csv`.
3. Gunakan `HR Summary.png` dan `mockups.drawio` sebagai acuan tata letak.
4. Baca `Summary OverView.docx` untuk ringkasan analisis.
